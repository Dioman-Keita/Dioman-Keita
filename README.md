## Engineering Principles

- **Product understanding before implementation.** Code follows from the problem, not the other way around.
- **Runtime safety matters as much as type safety.** Types are a tool, not a guarantee.
- **Simplicity scales better than cleverness.**
- **Developer experience is a feature.**
- **Build in public, learn in public.**
